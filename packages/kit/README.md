# @moco/kit

The quality bar. Layered SVG React components with a shared rig (blink, mouth, arm raise, head tilt, expression):

- `characters/`: Krishna, Arjuna, …
- `props/`: chariot, horse, …
- `backgrounds/`: Kurukshetra, palace, forest, … (parallax layers)

Organised so packs (Ramayana, Shiva, Mahabharat) can be sold as add-ons.
